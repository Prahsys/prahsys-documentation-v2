# Setup your Prahsys account

This guide is for getting started with your Prahsys account. Follow the steps below to create an account and generate your API keys.

### Create a Prahsys Account

1. Navigate to [Prahsys Dashboard](https://dashboard.prahsys.com)
2. Fill in your details (email, password, etc.)
3. Verify your email address through the confirmation link

### Generate API Keys

1. In the dashboard, locate and click on "API Keys" on the sidebar
2. Click the "New API Key" button
3. Give your key a descriptive name (e.g., "Development", "Production")
4. Click "Create " to generate your new API key
5. Copy and securely store your API key (Note: It will only be shown once)
